## 残留代码和配置处理

- 删除无引用的 EVENT_ADDON、DIFFICULTY_LABELS、disconnectWs 和未使用导入。
- 删除前端 myAttrs 第二套属性缓存，玩家属性以服务端房间快照为准；私有属性消息仍可用于提示。
- 删除不执行的 consume_rule 字段及旧手工开户实现。
- tie_break 现在参与排名及全灭胜负计算。仅允许 hp_peak、survived_turns，按配置顺序比较；完全相同仍为平局；异常终止不会用该机制选赢家。
- appeal 保留为可选的旧包兼容配置，字段说明明确“不执行上诉”；删除 appeals_left 和无消费的上诉/判例事件枚举，避免维护虚假的运行时状态。
- 字段说明标明 max_exchange_rate 为旧包兼容字段，不再暗示手工兑换功能存在。
- Python 同一作用域函数/类重复定义扫描未发现覆盖式重复定义。未使用导入候选检查发现的 Optional 已移除。

## 关联边界修复

- 新连接接管后，旧连接不能再提交操作或清理新连接的座位。
- 前端等待 session 认证完成再执行创建/加入动作，避免仅 WebSocket 已打开就提前发送。
- 前端清理重连计时器，并忽略旧 socket 的迟到事件。
- 赢家离开结束页面后保留本局结果；返回大厅时移除离线真人席位，避免下一局被幽灵席位阻塞。
- 玩家离开旧局并加入新房间后，旧局不再向其发送私有属性通知。
- 自动对局验收新增生命状态一致性和异常结束检查，防止“提前报 over”被误判为成功。
