# 可组合效果系统实施记录

## 计划

1. 定义严格的宣言要求、效果动作、触发时机、结束条件和时间单位；不使用技能名决定行为。
2. 实现确定性编译和独立语义复核；遗漏、未知字段、替换结束条件或无法复核均不执行，不以模板替代复杂机制。
3. 接入统一效果运行时：直接伤害/治疗/吸取、周期动作、目标限制、冻结、护盾、防御、条件触发、解除和生命周期。
4. 由实际执行状态生成规则描述、裁判上下文和前端展示；移除右下角提示功能。
5. 增加语义保真、时间单位、触发边界和状态重放测试，完成后端、前端及离线验证。

## 时间约定

默认“持续 N 回合”为建立后 N 次全局行动机会；建立回合不扣次数。明确“目标自己的回合”使用目标行动机会；“轮”使用生效时存活玩家各获得一次行动机会，死亡玩家不阻塞轮转。被冻结的行动机会仍计数。持续效果在最后一次有效机会结束后到期；有限血量条件独立检查，不能替代时间条件。

## 已实现（2026-11-18）

玩家宣言现在经过 `judge_ai.adjudicate → DeclarationPlan → validate_plan → SemanticReview → EffectRuntime`。
提取与审核是两次独立模型请求，使用房主/服务器配置，分享总超时预算；审核不接收提取过程的推理。
最多尝试三轮，任何一轮都须同时通过严格结构检查、引用/全文覆盖检查与独立语义审核才进入运行时。
未知字段、遗漏原文、重复引用同一片段、无效玩家/效果引用均拒绝，不能用旧 duels 输出绕过。
引擎编译只执行显式的平衡钳制并记录原因，不改写对象、时间单位、解除条件或不可破坏属性。

| 组成部分 | 已支持的行为 |
| --- | --- |
| 动作 | 伤害、治疗、按实际扣血量吸取并治疗、目标限制、跳过行动、护盾、固定护甲、百分比减伤、解除效果 |
| 对象 | 明确玩家集合、集合中最低当前血量者；同血量按座位顺序 |
| 触发 | 即时、持续被动、全局行动开始、指定玩家行动开始、受伤后、格挡后、指定效果被主动解除后 |
| 条件 | 任一指定存活玩家血量严格低于比例；独立的结束条件在跨过阈值或指定玩家死亡时解除 |
| 时间 | 即时、全局行动次数、指定玩家行动机会、轮、无时间截止；有限时长 1–1000，不再静默压到9 |
| 修改 | 显式引用效果 ID 修改完整规格；续期必须明确 renew；改名、续期或重排动作不补充已消耗的格挡次数 |
| 引用 | 同一宣言用 local_id 引用前面新建的持续效果，运行时转换成真实 ID |

技能名字仅用于展示。旧的 `DuelRule`、关键词强制生成决斗、专用决斗 UI 和默认不可取消规则已移除。
“只能互相攻击”仅约束攻击伤害，不禁止第三方治疗或辅助；多个限制取交集。
不可提前解除需明确声明，且不妨碍自然到期；引用受保护/不存在效果的解除要求整体受阻。
不支持或歧义的不可分割要求整体不执行，其他独立要求可执行，战报逐项说明。

## 执行与状态

- 同次结算的计划、周期和连锁动作共享伤害/治疗预算；护甲创建值受扩展包属性上限约束。
- 同一监听器每次结算最多触发一次；事件队列最多128项、深度8，最多64个活动效果，并遵守每个玩家的属性数量上限。达到边界会生成未执行/受限记录。
- 护盾次数按每个对象独立计数，最后一次格挡仍可触发回血；仅致命护盾按护甲和减伤后的预计伤害判定。
- 吸取治疗量来自实际生命损失，格挡时为零，致死时不超过目标剩余生命；已出局者不被治疗复活。
- 结果、扣血消息、死亡/继承广播、规则说明、快照及前端效果卡片都来自执行记录和实际状态。
- 活动效果完整规格、剩余时间、格挡次数、轮转等待集合进入快照；裁判和困难/炼狱 AI 假人能读取既有效果上下文。
- 房间重开清空效果；冻结行动机会仍执行到期计数。血量条件一旦满足，即使同次结算随后回血也不重新生效。

## 兼容边界

保留扩展包已有的属性和环境事件格式。旧属性的护盾/护甲/减伤与新声明攻击共同结算；旧模板/兼容裁决的直接伤害同样服从新护盾及目标限制。
环境事件、天灾和旧属性的周期扣血保留原有直接结算语义，不受普通攻击防御拦截；它们会通知通用受伤触发器并即时检查结束条件，不重复扣血。
扩展包属性保留正面外壳继承；通用效果使用下述独立继承路径，不转换成旧属性。环境 judged 事件仍使用原有事件裁判格式，新增声明管线不冒充对所有事件文本都完成语义证明。

通用 armor 目前是固定抵扣量；旧属性保留已有磨损规则。攻击数值属性、复杂装备磨损、时间回滚、任意程序逻辑等超出动作集合的要求须明确标为 unsupported。
旧属性的复杂改写不猜测迁移成通用效果；对旧属性的显式解除仍支持且遵守不可破坏。
以后新增机制应扩展动作/触发/条件的结构、验证、解释器和测试，不能按技能名字追加分支。

裁判关闭或代理不连通时，只执行完整匹配的攻击、治疗、定时护甲、冻结、护甲强化、显式解除后攻击模板；其余宣言显示未执行。强化/解除核对真实效果 ID、名称和对象，受保护解除要求整体拒绝。代理已连接但提取/审核失败时不再调用近似模板裁决。
人类仍手写宣言；仅困难/炼狱假人尝试 AI 发言，失败回落模板；开发面板的 AI 扩展包生成功能保留。

## 继承与假人适配补充（2026-11-18）

- 新旧能力共同参与候选选择，每次击杀只继承一个。旧属性排除冻结、负向周期扣血、零值和已过期外壳；新效果只允许护甲、减伤、护盾和可独立转移的治疗。任何含负面动作的混合效果整体排除。
- 新效果候选在死亡清理前捕获，旧属性数值也做独立快照；后续修改不能改变死亡当时的候选。旧属性仍走外壳折算，通用效果保持原动作和触发方式。
- 通用效果数值与剩余护盾次数按包比例折算（四舍五入、正数下限1），耗尽的护盾不恢复；无限护盾保持无次数限制。剩余时间和轮转进度不重置，自身触发/条件/时钟改绑继承者；多人正面效果只转移死者一份，不修改其他受益者。
- 依赖其他玩家条件、动态最低血量选择或其他效果引用的能力暂不继承，不删除依赖后强行转移。继承者已满足结束条件则不授予；容量仍合并计算，并遵守全局活动效果上限。
- 候选强度排序仅用于稳定选取：旧属性 value/cap，通用效果为动作数值与剩余次数之和，无限盾按1计入。战报展示实际动作和折算结果，不把不同单位的排序分数当成伤害。
- 保留当前周期/连锁伤害的创建者归属，可触发正面能力继承；自伤、环境无来源伤害、创建者已死时不继承。不会按滞后的 P2 规则恢复“所有周期击杀均无继承”。
- 假人模板读取通用防御、冻结、保护、攻击目标限制与合计容量；创建定时护甲、强化真实护甲 ID、显式解除后攻击都可以离线完整编译。含糊的装备创建/升级和无效果的犹豫模板不再由假人生成。重名目标用无歧义的自身动作回退。
- 真人仍手写宣言；困难/炼狱仍优先模型发言；只在裁判关闭或代理不可用时走严格模板匹配。UI、发布准备和日志策略本轮均未调整。

本轮新增31项回归测试（`test_inheritance_effects.py`、`test_bot_templates.py`）；完整后端236项通过。三个内置包各3局、每局4假人的离线验证共9局通过。未调用真实模型。
